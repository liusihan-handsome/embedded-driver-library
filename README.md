# 嵌入式常用外设与元器件驱动

这是一个用于整理和分享嵌入式学习过程中积累的外设及常用器件驱动的代码仓库。希望这些代码能为查阅资料、验证功能和项目移植提供参考，减少重复编写基础驱动的时间，也欢迎大家交流改进。

仓库内容主要面向 **STM32F1**，包含基于 **STM32 HAL 库**和**标准外设库（标准库）**编写或移植的代码。不同目录可能来自不同工程，接口和依赖尚未统一；请将其作为学习与移植参考，而非保证可直接加入任意项目的完整软件包。

## 移植说明

移植到自己的 STM32F1 工程前，建议先阅读对应 `.c`、`.h` 文件，并检查以下内容：

1. **库类型与工程依赖**：确认代码使用 HAL 还是标准外设库。不同目录的实现方式可能不同，也可能依赖 `main.h`、`sys.h`、FreeRTOS 等工程文件；请按目标工程替换或补齐依赖。
2. **引脚和外设配置**：核对 GPIO 端口、引脚、复用功能、SPI/I²C/UART/TIM 等外设实例，以及时钟使能和中断配置。
3. **时序与延时**：检查系统时钟、定时器和延时函数是否满足器件数据手册的要求。
4. **编译与硬件验证**：将所需源文件加入工程，解决接口或宏定义差异后，再结合目标硬件验证读写、通信和时序。

代码来自不同学习和开发场景，暂不保证所有目录都能在同一工程中直接编译，也不代表已经在所有芯片型号、库版本或硬件模块上完成验证。涉及电源、电能测量或执行器的代码，使用前请结合硬件设计和器件手册进行检查。
